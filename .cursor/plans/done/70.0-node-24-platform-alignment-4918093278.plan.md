support-contract change, explicitly approved as direction by the parent policy;
record it in migration/support guidance without selecting or bumping a release.
Root package engines use the proven Node 22 minimum; private server/frontend demo
projects use Node 24. All three manifests declare the same exact agreed manager,
retain separate locks, and root `.nvmrc` selects Node 24. Exact floor patches follow
proof. An existing 5.0.6 artifact may suffice for interim app runtime tests, but changed
packed engines/dependency metadata needs later user publication to reach consumers.

demo projects target their own Node 24 development contract. Keep explicit floor/next

# 69.0 HTTP audit omits the application label

## Problem

Miso dev01, 2026-10-15: Audit & Logs → application filter lists `***MASKED***`. Cause:
commit `c47e0b6` (5.0.3) added `application: "***MASKED***"` to:

- `src/utils/http-client-audit.ts` — `handleMinimalAudit` (87), `buildAuditContext` (276),
  `buildDebugContext` (409);
- `src/utils/http-client.ts` — 125, 147, 268, 279.

68.0 intent: do not send the credential-derived application label. A placeholder is still a label,
and Miso stores it as the producer's name.

## Decision

Omit the field. The logger's normal resolution fills `application` (client-token application,
else clientId app part, else clientId). The user accepted this clientId-derived label on
2026-10-15: clientId is a non-secret identifier, so 68.0's masking of this fallback is relaxed.
Miso plan 279.0 also ignores placeholder values for SDKs already deployed.

- Remove `application` from the seven automatic HTTP audit/debug context sites.
